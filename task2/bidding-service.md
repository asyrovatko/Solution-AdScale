## Сервиса ставок (Bidding Service)

### Описание

> Получает список подходящих объявлений и за десятки миллисекунд отвечает: **кого показать и по какой цене**. 
> Резервирует деньги, но не списывает. 
> Настройки кампаний не хранит - держит их копию в кэше.

### Границы

Входит в зону ответственности:
 - подбор кандидатов
 - расчёт ставки по стратегии 
 - вызов аукциона
 - резервирование бюджета
 - формирование контрактов
 - формирование bid response
 - Обновление кеша по событиям

Не входит в зону ответственности: 
 - формирование баннера
 - списание денег
 - прямые запросы в базы других сервисов

### Устройство сервиса 

| Часть                   | Роль                                                                                   | Технология                 |
|-------------------------|----------------------------------------------------------------------------------------|----------------------------|
| **Istio Sidecar**       | Прокси: шифрование, проверка сертификатов, телеметрия                                  | Envoy / Istio Proxy        |
| **Ad API**              | Принимает HTTP-запросы партнёра, Формирует события kafka, формирует bid response       | Go / HTTPS OpenRTB         |
| **Ad Server**           | Определяет пользователя, подбирает кандидатов, применяет поправки, формирует контракты | C++                        |
| **Update Cache Worker** | Обновляет кэш ставок по событиям из Kafka                                              | Go / gRPC / Kafka consumer |
| **Redis Cluster**       | Кэш: кампании, стратегии, контент, баннеры, таргетинг, бюджеты, рассчитанные ставки    | Redis 7                    |

### API

| Метод                  | Тип вызова            | Что делает                                                                                            | Кто вызывает                             | Время ответа | Повтор безопасен    |
|------------------------|-----------------------|-------------------------------------------------------------------------------------------------------|------------------------------------------|--------------|---------------------|
| `Bid`                  | Входящий/Синхронный   | Принимает запрос рекламы, возвращает контракты и баннеры либо `no-bid`                                | API Gateway через Istio Sidecar          | 80ms         | Да, по `auction_id` |
| `GetCacheState`        | Внутренний/Синхронный | Отдаёт состояние кэша: заполнен или пуст                                                              | Ad API внутри сервиса                    | 2ms          | Да                  |
| `auctionRequest`       | Исходящий/Синхронный  | Запускает аукцион по списку кандидатов и их ставкам, возвращает победителя и победную ставку [2.AU.1] | Ad Server через Istio Sidecar            | 30ms         | Да                   |
| `campaign_changed`     | Consumer/Асинхронно   | Обновляет кампании в кеше                                                                             | Update Cache Worker через Istio Sidecar  | -            | Да                   |
| `content_changed`      | Consumer/Асинхронно   | Обновляет контент в кеше                                                                              | Update Cache Worker через Istio Sidecar  | -            | Да                   |
| `strategy_changed`     | Consumer/Асинхронно   | Обновляет стратегии в кеше                                                                            | Update Cache Worker через Istio Sidecar  | -            | Да                   |
| `state_budget_changed` | Consumer/Асинхронно   | Обновляет состояние бюджета в кеше                                                                    | Update Cache Worker через Istio Sidecar  | -            | Да                   |
| `targeting_changed`    | Consumer/Асинхронно   | Обновляет агрегаты по пользователям и кмпания в кеше                                                  | Update Cache Worker через Istio Sidecar  | -            | Да                   |
| `bid_cache_init`       | Produser/Асинхронно   | Запрос сбора кеша                                                                                     | Ad API                                   | -            | Да                   |
| `bid_cache_init`       | Consumer/Асинхронно   | Собирает кеш                                                                                          | Update Cache Worker через Istio Sidecar  | -            | Да                   |
| `contract_create`      | Produser/Асинхронно   | Оправляет информацию о контрактах                                                                     | Ad API                                   | -            | Да                   |

### Зависимости

|  Зависимость                 |  Тип                                  | Если недоступна                                                                                        |
|------------------------------|---------------------------------------|--------------------------------------------------------------------------------------------------------|
| **Redis Cluster (bidCache)** | Критическая                           | Сервис отвечает `cache_empty` и запускает инициализацию; до её завершения отдаёт `no-bid`, но не ошибку |
| **Auction Service**          | Критическая для собственного аукциона | Работает ветка "создать резерв бюджета кандидата" без проведения аукциона [2.R.4]                       |
| **Kafka**                    | Важная                                | Аукционы продолжают идти на текущих данных кэша; обновления кэша откладываются                         |
| **Campaign Service**         | Только при обновлении кэша            | В кэше остаются предыдущие версии кампаний                                                             |
| **Statistics Service**       | Только при обновлении таргетинга      | Таргетинг в кэше не обновляется                                                                        |
| **Financial Service**        | Только при обновлении бюджета         | Состояние бюджета в кэше остаётся прежним                                                              |
| **Delivery Service**         | Только при обновлении баннеров        | Кэш баннеров не обновляется                                                                            |
| **Чужие базы данных**        | Зависимости нет                       | -                                                                                                      |

### Модель данных

| Сущность                                        | Хранилище                   | Ключ        | Источник истины                 |
|-------------------------------------------------|-----------------------------|-------------|---------------------------------|
| Кампании для аукциона                           | Redis `campaigns`           | campaign_id | Campaign Service                |
| Стратегии, правила, поправки                    | Redis `strategy`            | strategy_id | Campaign Service                |
| Контент                                         | Redis `content`             | content_id  | Campaign Service                |
| Баннеры                                         | Redis `banners`             | banner_id   | Delivery Service                |
| Таргетинг по пользователю                       | Redis `users_targeting`     | user_id     | Statistics Service              |
| Таргетинг по кампании                           | Redis `campaigns_targeting` | campaign_id | Statistics Service              |
| Состояние бюджета                               | Redis `state_budgets`       | campaign_id | Financial Service               |
| Бюджеты, резервы, агрегаты, рассчитанные ставки | Redis (производные)         | campaign_id | Bidding Service (вычисляет сам) |
| Результаты аукционов                            | ClickHouse (Auction)        | auction_id  | Auction Service                 |

### Нефункциональные требования

| Параметр                              | Значение                                                          |
|---------------------------------------|-------------------------------------------------------------------|
| Бюджет времени на весь запрос рекламы | Меньше 80 мс p99 (задано на диаграмме сценария 2)                 |
| Ответ при пустом кэше                 | `no-bid` быстрее, чем полный тайм-аут                             |
| Обновление кэша после события         | В пределах применения события воркером                            |
| Доступность                           | Обеспечивается репликами Redis и несколькими экземплярами сервиса |
| Резерв бюджета                        | Возвращается в бюджет, если показ не состоялся                    |
